HSK 3 STUDY & WRITING FOR IPHONE
Classic 600-word deck for the 7 November 2026 exam

WHAT THIS VERSION ADDS

- A touch handwriting page designed for iPhone and Apple Pencil.
- One short Chinese example sentence for every one of the 600 words.
- Pinyin and English translation for every example.
- Word meaning, pronunciation, character selection, a tracing guide, undo,
  clear, guide hiding, and writing-practice counts on the same page.
- The original flashcards, spaced review, vocabulary list, study plan, backup,
  and progress tracking.

IMPORTANT: HOW AN IPHONE WEB APP IS INSTALLED

Apple requires a home-screen web app to be opened from a secure HTTPS website.
The ZIP itself cannot be installed as a native IPA by tapping it in Files.

1. Upload every file and folder in this package to one HTTPS static website.
   GitHub Pages, a university website, or another static host will work.
2. Open that website's URL in Safari on the iPhone.
3. Tap Share, choose Add to Home Screen, turn on Open as Web App, then tap Add.
4. Open HSK 3 from the new Home Screen icon while connected. In Settings, wait
   until Offline installation says "Offline ready on this device."

For a computer preview, keep all files together and open index.html in Edge,
Chrome, or Safari. Home-screen installation and offline caching require HTTPS.

HANDWRITING PAGE

Open Write from the bottom navigation. Choose a word, then practise each
character in order, including repeated characters. Trace the pale model with a
finger or Apple Pencil. Hide the guide and write again from memory. The app
enables I wrote this word after every character has been attempted.

The drawing pad teaches character shape and proportion. It deliberately does
not claim to recognize handwriting or judge stroke order. Use a teacher or a
trusted stroke-order reference when learning a completely new character.

BACKUP AND PRIVACY

Progress and handwriting counts stay in the Safari web-app storage on this
device. Use Settings > Export backup regularly and before clearing Safari data,
moving to another iPhone, or reinstalling the app. No study data is uploaded.

EXAM VERSION

This app follows the classic cumulative HSK 3 list of 600 cards from the
supplied PDF. Confirm the version on the registration confirmation. If the test
centre says HSK 3.0, this 600-word deck is not a complete syllabus.
